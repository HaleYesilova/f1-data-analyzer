#Formula 1 Championship Analyzer (Preswald App)

An interactive data analysis app built using [Preswald](https://preswald.com), analyzing key trends in Formula 1 history from 1950 to 2009.

## 💡 What It Does
- Shows top 10 drivers by race wins (with SQL query)
- Interactive slider to filter drivers by wins
- Highlights top constructors and race circuits
- Full dashboard experience using `hello.py`

## Files
- `hello.py`: The main Preswald app
- `preswald.toml`: Project config
- `data/`: Includes `results.csv`, `drivers.csv`, etc.
- `images/`: Custom logo and favicon

## How to Run Locally
1. Clone the repo
2. Install [Preswald](https://github.com/StructuredLabs/preswald)
3. Run the app:
```bash
preswald run
